# CV Material

This repository is a working archive of the coursework, reports, experiments, and research projects behind my CV. Each top-level folder maps to a university module, dissertation, or substantial independent project.

The aim of this README is to make the archive quick to understand:

- what each module is about
- what kind of work lives in the folder
- where to start if you only want the strongest examples

## How To Read This Repository

- Most folders combine code, write-ups, plots, and raw coursework artefacts.
- Dissertation folders are primarily final PDF submissions and supporting documents.
- Some modules include third-party libraries, generated build files, or lab scaffolding because this is preserved as a working archive rather than a cleaned showcase repo.
- If a folder is light on material, that is called out explicitly below.

## Security and archival use

This is a historical coursework archive, not a production software distribution. Some projects retain old dependencies and educational servers that should not be deployed or exposed to a public network. Run unfamiliar code only in an isolated local environment, keep services bound to localhost, and supply any required credentials through untracked environment variables rather than source files. Never reuse real credentials with these projects.

## Module Guide

The summaries below describe the focus of each folder rather than the full official syllabus.

### Artificial Intelligence, Machine Learning, and Neuroscience

- [AI With Logic Programming](<./AI With Logic Programming/>): declarative problem solving with Prolog, including unification, backtracking, symbolic search, and rule-based reasoning. The folder contains coursework, logic-programming exercises, and test cases.
- [Advanced Natural Language Processing](<./Advanced Natural Language Processing/>): language modelling, corpus processing, and distributional semantics. The folder includes Python coursework, reports, and experiment plots.
- [Applied Deep Learning](<./Applied Deep Learning/>): deep neural networks for vision-style tasks, with emphasis on experiment analysis and model behaviour. The folder is centred on report-backed experiments, figures, and Python code.
- [Biologically Inspired AI](<./Biologically Inspired AI/>): bio-inspired computation, dynamical systems, and neural or evolutionary modelling. The folder contains MATLAB and Haskell simulations.
- [Computational Cognitive Neuroscience](<./Computational Cognitive Neuroscience/>): computational models of memory, learning, and spiking neurons. The folder includes Python and MATLAB work, reports, and many generated plots.
- [Computational Neuroscience](<./Computational Neuroscience/>): numerical modelling of neurons and neural systems, supported by simulation code and formal write-ups. The folder contains substantial code, tests, and reports.
- [Machine Learning](<./Machine Learning/>): supervised learning workflows, model evaluation, and notebook-based experimentation. The folder includes scikit-learn labs, assessed notebooks, and project work.
- [Neural Information Processing](<./Neural Information Processing/>): neural data analysis and information-processing experiments, represented mainly through plots and report artefacts.
- [Probabilistic Modelling and Reasoning](<./Probabilistic Modelling and Reasoning/>): Bayesian reasoning, posterior analysis, and probabilistic programming. The folder contains Python and Stan coursework plus supporting figures.
- [Reinforcement Learning](<./Reinforcement Learning/>): learning agents, environment interaction, and policy evaluation. The folder combines coursework base code, custom implementations, and simulation assets.
- [Robotics](<./Robotics/>): localisation, sensing, and behaviour in simulated robotics environments. The folder contains MATLAB BotSim exercises and course materials.
